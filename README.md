# Trahere

Trahere adalah aplikasi gambar digital yang berfokus pada kemudahan penggunaan. Sekarang, pada aplikasi digital drawing banyak pemula terhambat karena kompleksitas, kebutuhan spesifikasi tinggi, atau biaya subscription. Trahere menawarkan alternatif yang lebih sederhana.

## Ringkasan Fitur
- Layer: untuk memisahkan canvas lainnya.
- Brush: untuk menggambar.
- Eraser: hapus bagian gambar dengan alat penghapus.
- Fill: isi area pada canvas tertutup dengan warna yang dipilih.
- ORA: buka/simpan file OpenRaster.
- Recent files: daftar file terakhir yang diakses.

## Tools
- Qt
- C++1
- OpenGL
